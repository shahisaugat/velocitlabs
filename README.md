# Velocit Technologies - Premium Professional Website

A stunning, modern website for Velocit Technologies built with React, Tailwind CSS, and Framer Motion. Features a fully responsive design with smooth animations, comprehensive sections, and enterprise-grade UX.

## 🚀 Features

### Core Sections
- **Navigation Bar** - Sticky header with mobile-responsive menu
- **Hero Section** - Eye-catching landing with gradient text and metrics
- **Features** - 8 key features showcased in an interactive grid
- **Services** - 4 premium service offerings with detailed descriptions
- **Case Studies** - Success stories from enterprise clients
- **Testimonials** - 4 client testimonials with ratings
- **Pricing** - 3-tier pricing model with billing toggle
- **Contact CTA** - Email signup and contact information
- **Footer** - Comprehensive footer with links and social media

### Design Highlights
- ✨ Smooth animations with Framer Motion
- 📱 Fully responsive across all devices
- 🎨 Premium color scheme with gradients
- ⚡ Optimized performance (Vite + React)
- 🔒 Modern, professional aesthetic
- ♿ Semantic HTML for accessibility
- 🌐 SEO-optimized meta tags

## 🛠️ Tech Stack

- **React 19** - UI framework
- **Tailwind CSS 4** - Utility-first styling
- **Framer Motion** - Advanced animations
- **Lucide React** - Beautiful icon library
- **Vite** - Lightning-fast build tool

## 🚀 Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```
Runs dev server at http://localhost:5173

### Build
```bash
npm run build
```
Creates optimized production build in `dist/`

### Preview
```bash
npm run preview
```
Preview production build locally

### Lint
```bash
npm run lint
```
Check code quality with ESLint

## 🎨 Customization

### Colors & Branding
Edit `src/styles/index.css` theme variables:
```css
@theme {
  --color-primary: #2563EB;
  --color-primary-hover: #1D4ED8;
  /* ... more colors */
}
```

### Content
Update component content directly in each component file:
- Company name, descriptions in `Navbar.jsx`
- Features list in `Features.jsx`
- Pricing plans in `Pricing.jsx`
- Case studies in `CaseStudies.jsx`
